1. 직류회로의 기초

📝 나만의 메모

옴의 법칙

V = I × R (전압 = 전류 × 저항)

저항의 직렬 합성

R = R1 + R2 + R3 + ... (그냥 더한다)

저항의 병렬 합성

1/R = 1/R1 + 1/R2 + ... (역수의 합의 역수)

키르히호프 전류법칙 (KCL)

한 절점에서 유입 전류의 합 = 유출 전류의 합

키르히호프 전압법칙 (KVL)

한 폐회로에서 전압강하의 합 = 기전력의 합

전력

P = VI = I²R = V²/R [W]

✏️ 단원 확인문제 (5문제)
점수: 0 / 100점 (정답 0 / 5문제)

Q1. 옴의 법칙을 바르게 나타낸 것은?

💡 해설: 옴의 법칙은 전압 V = 전류 I × 저항 R 입니다.

Q2. 2Ω, 3Ω, 6Ω 저항을 병렬로 연결했을 때 합성저항[Ω]은? (숫자만 입력) (단답형)

💡 해설: 1/R = 1/2+1/3+1/6 = 1 이므로 R = 1Ω 입니다.

Q3. 키르히호프의 전류법칙(KCL)에서 한 절점에 유입하는 전류의 합과 유출하는 전류의 합은?

💡 해설: KCL: 한 절점에서 유입 전류의 합은 유출 전류의 합과 같습니다.

Q4. 10Ω 저항에 2A의 전류가 흐를 때 소비전력[W]은? (숫자만 입력) (단답형)

💡 해설: P = I²R = 2² × 10 = 40W 입니다.

Q5. 저항 두 개를 직렬로 연결하면 합성저항은 각 저항보다 어떻게 되는가?

💡 해설: 직렬연결은 저항값을 단순히 더하므로 합성저항이 커집니다.

2. 회로망 해석법

📝 나만의 메모

중첩의 정리

여러 독립 전원이 있을 때, 전압원은 단락 · 전류원은 개방하고 각각 해석해 합산한다.

테브난의 정리

임의의 선형회로를 등가전압원(Vth)과 직렬저항(Rth)으로 등가화.

노턴의 정리

임의의 선형회로를 등가전류원(IN)과 병렬저항(RN)으로 등가화. IN = Vth/Rth, RN = Rth

등가저항 구하기

전압원은 단락, 전류원은 개방시킨 뒤 남은 저항으로 계산.

밀만의 정리

여러 병렬 전압원(가지)의 등가 전압을 한 번에 구하는 공식.

✏️ 단원 확인문제 (5문제)
점수: 0 / 100점 (정답 0 / 5문제)

Q1. 여러 개의 독립 전원이 있는 선형회로를 해석할 때, 전압원은 단락, 전류원은 개방한 뒤 각각 해석해 합산하는 정리는?

💡 해설: 중첩의 정리는 여러 전원의 영향을 각각 따로 구해 합산하는 방법입니다.

Q2. 테브난 등가회로는 전압원과 무엇의 직렬 조합으로 구성되는가? (단답형)

💡 해설: 테브난 등가회로는 등가전압원(Vth)과 등가저항(Rth)의 직렬 조합입니다.

Q3. 노턴 등가회로는 전류원과 저항의 어떤 조합으로 구성되는가?

💡 해설: 노턴 등가회로는 등가전류원(IN)과 등가저항(RN)의 병렬 조합입니다.

Q4. 테브난 저항을 구할 때, 회로 내의 전압원은 어떻게 처리하는가? (단답형)

💡 해설: 등가저항을 구할 때 전압원은 단락(내부저항 0)으로 처리합니다.

Q5. 등가저항을 구할 때 회로 내의 전류원은 어떻게 처리하는가?

💡 해설: 전류원은 내부저항이 무한대이므로 개방으로 처리합니다.

3. 정현파 교류의 기초

📝 나만의 메모

순시값

v(t) = Vm sin(ωt + θ)

각속도

ω = 2πf [rad/s]

주기

T = 1/f [s]

실효값

정현파에서 실효값 = Vm/√2

평균값

정현파에서 평균값 = 2Vm/π

파고율 / 파형률

파고율 = 최댓값/실효값 = √2, 파형률 = 실효값/평균값 ≈ 1.11

✏️ 단원 확인문제 (5문제)
점수: 0 / 100점 (정답 0 / 5문제)

Q1. 정현파 교류에서 실효값과 최댓값의 관계로 옳은 것은?

💡 해설: 정현파의 실효값은 최댓값을 √2로 나눈 값입니다.

Q2. 주파수 60Hz인 정현파의 각속도 ω[rad/s]는? (소수점 없이 정수로 입력) (단답형)

💡 해설: ω = 2πf = 2π×60 ≈ 377 rad/s 입니다.

Q3. 정현파의 파고율(최댓값/실효값)은 약 얼마인가?

💡 해설: 정현파의 파고율은 √2 ≈ 1.414 입니다.

Q4. 정현파의 평균값을 최댓값(Vm)으로 나타낸 식은?

💡 해설: 정현파의 평균값은 2Vm/π 입니다.

Q5. 파형률은 실효값을 무엇으로 나눈 값인가? (단답형)

💡 해설: 파형률 = 실효값 / 평균값 으로 정의됩니다.

4. 페이저와 임피던스

📝 나만의 메모

저항 R

Z = R (전압·전류 동상)

인덕터 L

Z = jωL, 유도리액턴스 XL = ωL — 전류가 전압보다 90° 뒤짐(지상)

커패시터 C

Z = 1/jωC, 용량리액턴스 XC = 1/ωC — 전류가 전압보다 90° 앞섬(진상)

RLC 직렬 임피던스

Z = R + j(XL − XC)

✏️ 단원 확인문제 (5문제)
점수: 0 / 100점 (정답 0 / 5문제)

Q1. 인덕터(L)만의 회로에서 전류는 전압에 대해 위상이 어떻게 되는가?

💡 해설: 인덕터에서는 전류가 전압보다 위상이 90도 뒤집니다(지상).

Q2. 커패시터의 용량 리액턴스 Xc를 나타낸 식은?

💡 해설: 용량 리액턴스는 Xc = 1/(ωC) 입니다.

Q3. L=0.1H, f=60Hz일 때 유도 리액턴스 XL[Ω]은 약 얼마인가? (소수 첫째자리까지, 예: 37.7) (단답형)

💡 해설: XL = ωL = 2π×60×0.1 ≈ 37.7Ω 입니다.

Q4. RLC 직렬회로에서 XL > XC일 때 이 회로는 어떤 특성을 가지는가?

💡 해설: XL이 XC보다 크면 전체적으로 유도성 회로가 됩니다.

Q5. 순수 저항(R)만의 회로에서 전압과 전류의 위상차는 몇 도인가? (숫자만 입력) (단답형)

💡 해설: 저항 회로에서는 전압과 전류가 동상이므로 위상차는 0도입니다.

5. 교류전력

📝 나만의 메모

유효전력

P = VIcosθ [W]

무효전력

Q = VIsinθ [Var]

피상전력

S = VI = √(P²+Q²) [VA]

역률

cosθ = P/S

✏️ 단원 확인문제 (5문제)
점수: 0 / 100점 (정답 0 / 5문제)

Q1. 피상전력의 단위는 무엇인가?

💡 해설: 피상전력의 단위는 VA(볼트암페어)입니다.

Q2. 역률은 유효전력을 무엇으로 나눈 값인가? (단답형)

💡 해설: 역률 cosθ = 유효전력(P) / 피상전력(S) 입니다.

Q3. 무효전력의 단위는 무엇인가?

💡 해설: 무효전력의 단위는 Var(바)입니다.

Q4. V=100V, I=10A, 역률 0.8인 부하의 유효전력[W]은? (숫자만 입력) (단답형)

💡 해설: P = VIcosθ = 100×10×0.8 = 800W 입니다.

Q5. 역률이 1일 때 무효전력의 크기는?

💡 해설: 역률이 1이면 위상차가 0이므로 무효전력은 0이 됩니다.

6. 공진회로

📝 나만의 메모

직렬공진

XL = XC일 때 발생, 임피던스 최소(=R), 전류 최대

병렬공진

임피던스 최대, 전류 최소

공진주파수

f0 = 1/(2π√(LC))

선택도(첨예도) Q

Q가 클수록 공진곡선이 뾰족해지고 대역폭은 좁아진다

✏️ 단원 확인문제 (5문제)
점수: 0 / 100점 (정답 0 / 5문제)

Q1. RLC 직렬 공진회로에서 공진 시 임피던스는 어떻게 되는가?

💡 해설: 직렬공진 시 리액턴스 성분이 상쇄되어 임피던스는 저항 R만 남아 최소가 됩니다.

Q2. 직렬 RLC 공진회로의 공진주파수 공식은 f0 = 1/(2π√( ))이다. 괄호 안에 들어갈 것은? (단답형)

💡 해설: 공진주파수 f0 = 1/(2π√(LC)) 입니다.

Q3. RLC 병렬 공진회로에서 공진 시 회로에 흐르는 전체 전류는?

💡 해설: 병렬공진 시 임피던스가 최대가 되어 전체 전류는 최소가 됩니다.

Q4. 공진 조건에서 유도 리액턴스(XL)와 용량 리액턴스(XC)의 크기 관계는? (단답형)

💡 해설: 공진 조건은 XL = XC 입니다.

Q5. 선택도(첨예도) Q값이 클수록 대역폭은 어떻게 되는가?

💡 해설: Q값이 클수록 공진 곡선이 뾰족해져 대역폭은 좁아집니다.

7. 상호유도와 결합회로

📝 나만의 메모

결합계수

k = M/√(L1L2), 0 ≤ k ≤ 1

완전결합

k = 1일 때 — 누설자속 없음

가동(가극성) 결합

L = L1 + L2 + 2M

차동(감극성) 결합

L = L1 + L2 − 2M

이상적 변압기 권수비

a = N1/N2 = V1/V2 = I2/I1

✏️ 단원 확인문제 (5문제)
점수: 0 / 100점 (정답 0 / 5문제)

Q1. 결합계수 k를 상호인덕턴스 M과 자기인덕턴스 L1, L2로 나타낸 식은 k = M/√( )이다. 괄호 안은? (단답형)

💡 해설: 결합계수 k = M/√(L1L2) 입니다.

Q2. 결합계수 k=1일 때의 결합 상태를 무엇이라 하는가?

💡 해설: k=1이면 두 코일 사이에 자속의 누설이 전혀 없는 완전결합 상태입니다.

Q3. 가동(가극성) 결합일 때 합성 인덕턴스 L의 식은?

💡 해설: 가동결합은 자속이 서로 보강되므로 L = L1+L2+2M 입니다.

Q4. 이상적인 변압기의 권수비 a는 1차 권선수 N1을 2차 권선수 N2로 나눈 값이다. a의 정의를 식으로 쓰면? (단답형)

💡 해설: 권수비 a = N1/N2 = V1/V2 = I2/I1 입니다.

Q5. 이상적 변압기에서 1차 전압이 2차 전압보다 크다면 권수비 a는 1보다 어떻게 되는가?

💡 해설: a = V1/V2 이므로 V1 > V2이면 a는 1보다 큽니다.

8. 대칭 3상 회로

📝 나만의 메모

Y결선

선간전압 = √3 × 상전압, 선전류 = 상전류

Δ결선

선간전압 = 상전압, 선전류 = √3 × 상전류

3상 전력

P = √3 VL IL cosθ

위상차

대칭 3상의 각 상은 서로 120°씩 위상차를 가짐

✏️ 단원 확인문제 (5문제)
점수: 0 / 100점 (정답 0 / 5문제)

Q1. Y결선에서 선간전압과 상전압의 관계로 옳은 것은?

💡 해설: Y결선에서는 선간전압이 상전압의 √3배가 됩니다.

Q2. Δ결선에서 선전류는 상전류의 몇 배인가? (예: 1.73은 √3으로 입력) (단답형)

💡 해설: Δ결선에서는 선전류가 상전류의 √3배가 됩니다.

Q3. 평형 3상 회로의 전력을 나타낸 식으로 옳은 것은?

💡 해설: 3상 전력은 P = √3 VL IL cosθ 로 계산합니다.

Q4. 대칭 3상 전압에서 각 상 사이의 위상차는 몇 도인가? (숫자만 입력) (단답형)

💡 해설: 대칭 3상은 서로 120도씩 위상차를 가집니다.

Q5. Y결선에서 선전류와 상전류의 관계는?

대칭좌표법

불평형 3상을 정상분 · 역상분 · 영상분으로 분해해 해석

영상분

V0 = (1/3)(Va+Vb+Vc)

정상분

V1 = (1/3)(Va+aVb+a²Vc)

역상분

V2 = (1/3)(Va+a²Vb+aVc)

연산자 a

a = 1∠120°

완전 평형 시

정상분만 존재, 역상분·영상분 = 0

10. 비정현파 교류

푸리에 급수

왜형률(THD)

전고조파 실효값 / 기본파 실효값

반파대칭

기수(홀수) 고조파만 존재, 짝수 고조파 없음

직류분

파형 전체의 평균값에 해당

💡 해설: 비정현파는 푸리에 급수를 이용해 직류분+기본파+고조파의 합으로 표현합니다.
